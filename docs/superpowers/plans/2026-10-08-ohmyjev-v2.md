# ohmyjev v2 (lean) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Bring back the v2 batteries on top of v1, kept as lean as v1:
- an exfil gate on WebFetch and MCP;
- user `policies` that every gate weighs;
- the injection screen on Reads from outside the repo;
- a router for effort and subagent model;
- auto-compact when the task changes;
- an `ask_jev` tool;
- a `/jev` command.

**Architecture:** Same four files as v1. `policy.ts` gains the pure parts (questions, `decideRoute`, `routeStep`, `keepInstructions`, `summarize`, `buildQuestion`). `jev.ts` learns the `score` answer type. `ohmyjev.ts` gains the hooks. Every `$` function stays top-level in `ohmyjev.ts`, because the engine follows `$` only there.

**Spec:** `docs/superpowers/specs/2026-10-08-ohmyjev-mod-design.md` §§1–7 and "Log, status, /jev". The cuts and changes below take precedence over the spec.

## Global Constraints

- Everything in the v1 plan's Global Constraints still holds: fail open, never `ask`, fire-and-forget storage, deny text.
- **Not built:**
  - auto-approve: the user runs bypass mode, so there is no prompt to approve;
  - `pinnedStatus`: the user keeps their own statusline;
  - `logPayloads`: payloads are never logged;
  - `/jev doctor`'s live call: `/jev` reports key source, provider and model only;
  - `ask_jev`'s `each`, glob patterns and `command`: files are plain paths.
- **userConfig additions:**
  - **Switches:** `exfilGate` true, `screenReads` true (Reads outside the repo), `routeEffort` true, `routeSubagents` true, `routeMainModel` false, `autoCompact` true, `askJev` true.
  - **Thresholds and limits:** `exfil` 0.7, `routeUpgrade` 0.3, `routeDowngrade` 0.6, `routeRisky` 0.7, `compactSwitched` 0.8, `compactBoundary` 0.6, `compactMinPercent` 40.
  - **Models:** `fastModel` `claude-haiku-5-5`, `balancedModel` `claude-sonnet-5-5`, `deepModel` `claude-opus-5-5`.
  - **Policies:** `policies` is a `;`-separated string, empty by default.
- **Policies:**
  - **State:** a non-empty list goes into every gate's state as `policies`.
  - **Question:** every gate also asks `violates_policy`. A value at or above `bashDestructive`/`writeSecret`/`exfil` (whichever matches the gate) denies with reason `breaks a listed policy (p)`.
- **Status:** `SessionState` gains `compactions` and `lastRoute` (e.g. `↑opus/high`).
  - **Status text:** `jev ✓23 ⛔1 ↑opus/high 🗜2`.
  - **Python segment:** mirrors it.
- **Router (per turn):**
  - **When:** one Jev call in `turn.start`, skipped for a bare slash command or when every routing switch is off. The answer is held for the turn.
  - **`turn.step`:** main loop only (no `agentId`). Sets `effort` when `routeEffort` is on and the step's effort is a named level, and `model` only when `routeMainModel` is on.
  - **`agent.spawn`:** sets `model` to the tier's model when `routeSubagents` is on and `e.model` is unset.
  - **Bars:** up needs confidence ≥ 0.3, down ≥ 0.6. Risky (≥ 0.7) forces `deep` and at least `high`.
- **Auto-compact:**
  - **Questions:** `classic.Stop` adds `at_boundary` always, and `switched_gears` when previous requests exist.
  - **Decision:** `wantsCompact = switched_gears ≥ 0.8 && at_boundary ≥ 0.6`, held in memory.
  - **`session.measure`:** with `autoCompact` on, `wantsCompact` set and `context.percent ≥ 40`, it clears the flag, counts a compaction and calls `$.session.compact({ instructions: keepInstructions(request) })` fire-and-forget.
  - **`session.compact`:** with `trigger: 'auto'` and a known request, it appends the same instructions.
  - **Stop with `doneCheck` off but `autoCompact` on:** it still asks, but never blocks.
- **`ask_jev`:**
  - **Registration:** registered at `session.start` as `mcp__ohmyjev__ask_jev`.
  - **Input:** `{ question, type: noul|choice|score, options?, files?, state? }`.
  - **Files:** read with `$.fs.read`, clipped to 8000 chars each and 80000 total.
  - **Choice:** gets an `other` label when it's missing.
  - **Score:** takes 2–10 levels.
  - **Result:** the answer as a JSON string. An error comes back as `{"error": ...}` and is never thrown.
- **`/jev`:** registered at `session.start`.
  - **Output:** the session status line; calls, errors and cost from this session's log; denies per gate; the last 5 denies with reasons; key source, provider and model.
  - **Key:** the value is never shown.

## Review Focus

1. **The router never fails a turn:** Jev failing or slow leaves the step untouched.
2. **Auto-compact fires at most once per task change**, and never from a stale flag after `session.end`.
3. **`ask_jev` never throws into the model loop:** bad input comes back as an error JSON.
4. **Policies don't change any verdict when empty:** the questions and state are exactly v1's.

## Tasks

Each task is TDD: tests first, watch them fail, implement, then `claude plugin test .`, `bunx -p typescript@5.6.3 tsc -p .`, `claude plugin validate .`, and commit.

### Task 1: Exfil gate, policies, Read screen

**Files:**
- `policy.ts`: `EXFIL_Q`, `POLICY_Q`, `withPolicyQ`, `withPolicies`, `gateExfil`, policy deny in `gateBash`/`gateWrite`.
- `ohmyjev.ts`: `Read` joins HOOKED; screen when `screenReads` is on and the path is outside `session.root()`.
- `plugin.json`.

**Tests:**
- `gateExfil` thresholds.
- Policy deny via `violates_policy`.
- Empty policies keep v1 questions and state (no `violates_policy` key, no `policies` field).
- WebFetch exfil denied before it runs.
- Read of `/etc/x` flagged.
- Read in the repo not screened (no Jev request).

### Task 2: Router

**Files:**
- `jev.ts`: `score` validation (`0..levels-1`, optional confidence).
- `policy.ts`: `ROUTE_Q`, `decideRoute`, `pick`, `tierOf`, `modelOf`, `routeStep`.
- `ohmyjev.ts`: hooks on `turn.start`, `turn.step` and `agent.spawn`.

**Tests:**
- Score validation.
- `routeStep` up and down bars, risky forcing deep, unknown model treated as balanced.
- A `turn.step` hook beneath sees the routed effort.
- `agent.spawn` gets the tier model.
- Jev down leaves the step's effort as it was.

### Task 3: Auto-compact

**Files:**
- `policy.ts`: `STOP_Q.at_boundary`, `SWITCHED_Q`, `judgeStop` returns `{ block, wantsCompact }`, `keepInstructions`.
- `ohmyjev.ts`: Stop asks when `doneCheck` or `autoCompact` is on; hooks on `session.measure` and `session.compact`.

**Tests:**
- `judgeStop` compact verdict.
- Measure at 50% after a switched Stop calls compact once with instructions.
- Below 40% it does nothing.
- An auto compact gets the instructions appended.

### Task 4: `ask_jev` and `/jev`

**Files:**
- `policy.ts`: `buildQuestion`, `summarize(logLines)`.
- `ohmyjev.ts`: `session.start` registers both; `tool.call` on `mcp__ohmyjev__ask_jev`; `command.run` on `jev`.

**Tests:**
- `buildQuestion` errors.
- An `ask_jev` round trip with a file.
- A bad type returns error JSON.
- `/jev` output has the counts and the last deny, and never contains the key.

### Task 5: Status, statusline, README

**Files:**
- `statusText` and `jev_segment` show the route and 🗜.
- README sections for the v2 batteries.

**Tests:**
- `statusText` cases.
- The Python self-check.
