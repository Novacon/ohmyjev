# ohmyjev Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code plugin that puts TypeSafe's Jev decision model into hooks: bash/write/exfil gates with auto-approve, an injection screen, a done-check, a compact hint, an `omj ask` CLI + skill, a decision log, and a statusline segment.

**Architecture:** One stdlib-only Python file, `omj.py`. It talks to Jev over raw HTTP and holds pure gate functions `(answers, thresholds) -> verdict`, a hook dispatcher (`omj.py hook <Event>` reads Claude Code's hook JSON on stdin and prints the response JSON), and a small CLI (`ask`, `stats`, `doctor`). State lives in `~/.ohmyjev/`. The plugin is installed through a local marketplace at the repo root.

**Tech Stack:** Python 3.9+ standard library only (`urllib`, `json`, `argparse`, `subprocess`, `unittest`). Claude Code plugin hooks and skills.

**Spec:** `docs/superpowers/specs/2026-10-08-ohmyjev-design.md`

**Deviation from the spec layout:** the plugin lives in `plugins/ohmyjev/`, not at the repo root, because Claude Code's marketplace docs list relative plugin sources as `./plugins/<name>` from a root `.claude-plugin/marketplace.json`.

**Spec "verify while planning" items, resolved against code.claude.com docs (2026-10-08):**
1. A PreToolUse `"allow"` does **not** override settings deny/ask rules ("Deny and ask rules are still evaluated regardless of what the hook returns"). → Auto-approve stays in PreToolUse.
2. Stop input includes `stop_hook_active` and `last_assistant_message`. → Use them directly. The transcript is read only for user requests and tool names.
3. `${CLAUDE_PLUGIN_ROOT}` is substituted in plugin skill content and in `allowed-tools`. → The skill calls `python3 ${CLAUDE_PLUGIN_ROOT}/omj.py ask …`.
4. Output schemas:
   - PreToolUse: `{"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "allow|deny", "permissionDecisionReason": "..."}}`.
   - PostToolUse: `{"hookSpecificOutput": {"hookEventName": "PostToolUse", "additionalContext": "..."}}`. Tool output arrives in `tool_response` (str or JSON, depending on the tool).
   - Stop: `{"decision": "block", "reason": "..."}`.
   - Hook `timeout` is in seconds.

## Global Constraints

- **Python:** 3.9-compatible, standard library only. No `match`, and no runtime `X | Y` types (use `from __future__ import annotations`). Always run tests with `/usr/bin/python3` (macOS 3.9.6).
- **Decisions:** never return a `"ask"` permission decision. The user's agents run unattended. Outcomes are deny (with reason), allow, or no output.
- **Failure policy:**
  - Jev unreachable or malformed → no output (pass through), log the error, and set session `down_until = now + 300`.
  - Hooks always exit 0 and never raise.
- **Models:** TypeSafe `https://api.typesafe.ai/v1/systemone`, model `jev-1.13.0`. OpenRouter `https://openrouter.ai/api/alpha/decisions`, model `~typesafe/jev-latest`. TypeSafe wins if both keys are set. Config `model` overrides the model.
- **Timeouts:** HTTP 1.5 s, no retries. Hook `timeout` 5 (seconds) in `hooks.json`.
- **State:** `~/.ohmyjev/`, overridable with `OHMYJEV_HOME`. Log at `log.jsonl`. Sessions at `sessions/<sanitized session_id>.json`, written atomically.
- **Logging:** no commands or contents in the log unless config `log_payloads: true`.
- **Clip sizes:**
  - Bash command 4000 chars. Write content 4000. Exfil input 4000. Tool output 6000.
  - Stop fields: current_request 600, last_assistant_message 1500, each previous request 200.
  - `omj ask`: each file 8000, files total 80000, command output 20000.
- **Thresholds (defaults):** bash_irreversible 0.6, bash_destructive 0.7, approve_confidence 0.9, approve_destructive_max 0.2, write_secret 0.7, write_secrets_kind 0.8, exfil 0.7, injection 0.7, done_claimed 0.7, done_verified_max 0.3, done_asks_user_max 0.5, compact_switched 0.8, compact_boundary 0.6.
- **`BLOCK_NOTICE`, verbatim:** "This block is final. Do not try to work around it with another command, another tool, a different path, or an encoding that does the same thing. Stop and tell the user what was blocked and why."

## Review Focus

1. **Empty or invalid hook stdin, or a missing `tool_input`.** Expect silent pass-through and exit 0, never a traceback in Claude Code. Pinned in Task 3: `test_garbage_stdin_is_silent`, `test_missing_tool_input_still_gates`.
2. **Multi-megabyte write content or tool output.** Expect it clipped before it's sent to Jev, with no crash and no 32K-context error. Pinned in Task 3 `test_huge_content_clipped` and Task 4 `test_dict_response_flattened_and_clipped`.
3. **A hostile or odd `session_id` (`../../evil`).** Expect it sanitized, with the state file staying inside `~/.ohmyjev/sessions/`. Pinned in Task 3: `test_session_id_sanitized`.
4. **macOS path aliasing (`/tmp` → `/private/tmp`), symlinks, relative paths, `..`.** Expect the path resolved before the allow check, so no false denies and no escapes. Pinned in Task 2: the `path_allowed` tests.
5. **Jev answers with an unknown choice label, or omits a question.** Expect a contract error → pass-through, never a deny and never a crash. Pinned in Task 1 `test_jev_rejects_unknown_choice` and Task 3 `test_contract_error_passes_through`.

#!/usr/bin/env python3
"""ohmyjev: a Jev decision layer for Claude Code hooks.

Stdlib only, Python 3.9+. Claude Code calls `omj.py hook <Event>` with the hook JSON on stdin;
people and Claude call `omj.py ask|stats|doctor`. See README.md.
"""
from __future__ import annotations

import argparse
import json
import os
import re
import subprocess
import sys
import tempfile
import time
import urllib.request
from collections import Counter
from pathlib import Path

PROVIDERS = {  # name: (env var, endpoint, default model); both take the same request and return the same shape
    "typesafe": ("TYPESAFE_API_KEY", "https://api.typesafe.ai/v1/systemone", "jev-1.13.0"),
    "openrouter": ("OPENROUTER_API_KEY", "https://openrouter.ai/api/alpha/decisions", "~typesafe/jev-latest"),
}
USD_PER_INPUT_TOKEN = 0.042 / 1_000_000
TIMEOUT = 1.5  # seconds per HTTP call; hooks.json gives the whole hook 5

DEFAULTS = {
    "batteries": {
        "bash_gate": True, "write_gate": True, "exfil_gate": True, "auto_approve": True,
        "injection_screen": True, "done_check": True, "compact_hint": True,
    },
    "thresholds": {
        "bash_irreversible": 0.6, "bash_destructive": 0.7,
        "approve_confidence": 0.9, "approve_destructive_max": 0.2,
        "write_secret": 0.7, "write_secrets_kind": 0.8, "exfil": 0.7,
        "injection": 0.7, "done_claimed": 0.7, "done_verified_max": 0.3,
        "done_asks_user_max": 0.5, "compact_switched": 0.8, "compact_boundary": 0.6,
    },
    "policies": [],
    "allow_paths": ["~/.claude", "$TMPDIR", "/tmp"],
    "model": None,
    "log_payloads": False,
}


def home() -> Path:
    return Path(os.environ.get("OHMYJEV_HOME") or Path.home() / ".ohmyjev")


def load_config():
    """DEFAULTS merged with ~/.ohmyjev/config.json. Returns (cfg, error); a bad file falls back to defaults."""
    cfg = json.loads(json.dumps(DEFAULTS))
    try:
        user = json.loads((home() / "config.json").read_text())
        if not isinstance(user, dict):
            raise ValueError("top level must be an object")
    except FileNotFoundError:
        return cfg, None
    except (OSError, ValueError) as e:
        return cfg, f"config.json ignored: {e}"
    for key, value in user.items():
        if isinstance(cfg.get(key), dict) and isinstance(value, dict):
            cfg[key].update(value)
        elif key in cfg:
            cfg[key] = value
    return cfg, None


# --- Jev client ---

class JevError(Exception):
    """Jev gave no usable answer: no key, network, timeout, or a malformed response."""


def provider():
    for name, (env, url, model) in PROVIDERS.items():
        key = os.environ.get(env, "").strip()
        if key:
            return name, key, url, model
    raise JevError("no Jev key: set TYPESAFE_API_KEY or OPENROUTER_API_KEY")


def noul(instructions, true=None, false=None):
    q = {"type": "noul", "instructions": instructions}
    if true or false:
        q["criteria"] = {"true": true or "", "false": false or ""}
    return q


def choice(instructions, criteria):
    return {"type": "choice", "instructions": instructions, "criteria": criteria}


def score(instructions, levels):
    return {"type": "score", "instructions": instructions, "criteria": levels}


def validate(data, questions):
    """Every question answered with the right type and a numeric value; choices only from our own labels."""
    answers = data.get("answers") if isinstance(data, dict) else None
    if not isinstance(answers, dict):
        raise JevError("response has no answers")
    for qid, q in questions.items():
        a = answers.get(qid)
        if not isinstance(a, dict) or a.get("type") != q["type"]:
            raise JevError(f"missing or mistyped answer: {qid}")
        if q["type"] == "choice" and a.get("choice") not in q["criteria"]:
            raise JevError(f"{qid}: unknown choice {a.get('choice')!r}")
        field = {"noul": "noul", "choice": "confidence", "score": "score"}[q["type"]]
        if not isinstance(a.get(field), (int, float)):
            raise JevError(f"{qid}: {field} is not a number")
    return answers


def jev(state, questions, cfg=None, timeout=TIMEOUT):
    """One decision request. Returns (answers, meta). Raises JevError; callers own the failure policy."""
    name, key, url, model = provider()
    body = {"model": (cfg or {}).get("model") or model, "state": state, "questions": questions}
    req = urllib.request.Request(
        url, json.dumps(body).encode(),
        {"Authorization": f"Bearer {key}", "Content-Type": "application/json"},
    )
    started = time.monotonic()
    try:
        with urllib.request.urlopen(req, timeout=timeout) as resp:
            data = json.loads(resp.read())
    except (OSError, ValueError) as e:  # URLError, HTTPError and timeouts are OSError; bad JSON is ValueError
        raise JevError(f"{name}: {e}") from e
    answers = validate(data, questions)
    tokens = int((data.get("usage") or {}).get("input_tokens") or 0)
    return answers, {
        "provider": name, "model": data.get("model"),
        "ms": int((time.monotonic() - started) * 1000),
        "input_tokens": tokens, "cost_usd": round(tokens * USD_PER_INPUT_TOKEN, 9),
    }
```

def gate_bash(a, t, approve):
    effect, conf = a["effect"]["choice"], a["effect"]["confidence"]
    destructive = a["destructive_intent"]["noul"]
    if effect == "irreversible" and conf >= t["bash_irreversible"]:

# --- log and session state ---

DOWN_SECONDS = 300
WRITE_TOOLS = {"Write", "Edit", "MultiEdit", "NotebookEdit"}


def safe_sid(sid):
    return re.sub(r"[^\w-]", "", str(sid or "")) or "unknown"


def log(entry):
    d = home()
    d.mkdir(parents=True, exist_ok=True)
    with open(d / "log.jsonl", "a", encoding="utf-8") as f:
        f.write(json.dumps(entry, ensure_ascii=False) + "\n")


def session_path(sid):
    return home() / "sessions" / f"{safe_sid(sid)}.json"


def load_session(sid):
    try:
        s = json.loads(session_path(sid).read_text())
    except (OSError, ValueError):
        return {}
    return s if isinstance(s, dict) else {}


def update_session(sid, calls=0, denies=0, **fields):
    """Read-modify-write one session file; os.replace makes the write atomic for the statusline."""
    # ponytail: parallel hooks in one session can drop a counter increment; add a per-session lock if counts must be exact
    path = session_path(sid)
    path.parent.mkdir(parents=True, exist_ok=True)
    s = load_session(sid)
    s["calls"] = s.get("calls", 0) + calls
    s["denies"] = s.get("denies", 0) + denies
    s.update(fields)
    fd, tmp = tempfile.mkstemp(dir=path.parent, suffix=".tmp")
    with os.fdopen(fd, "w") as f:
        json.dump(s, f)
    os.replace(tmp, path)


def new_entry(hook, tool, sid):
    return {"ts": round(time.time(), 3), "session": safe_sid(sid), "hook": hook, "tool": tool}


def call(hook, tool, state, questions, cfg, sid, timeout=TIMEOUT):
    """Ask Jev. On failure: log it, mark the session down, return (None, None) so the caller passes through."""
    entry = new_entry(hook, tool, sid)
    if cfg["log_payloads"]:
        entry["state"] = state
    try:
        answers, meta = jev(state, questions, cfg, timeout)
    except JevError as e:
        entry["error"] = str(e)
        log(entry)
        update_session(sid, down_until=time.time() + DOWN_SECONDS)
        return None, None
    entry.update(meta)
    entry["answers"] = answers
    return answers, entry


def record(entry, sid, verdict, reason, **fields):
    """Log the decision and bump the session counters. Only a real Jev call clears the down flag."""
    entry.update(verdict=verdict, reason=reason)
    log(entry)
    denied = verdict in ("deny", "block")
    if denied:
        fields["last_deny"] = clip(f"{entry['tool'] or entry['hook']}: {reason}", 120)
    if "ms" in entry:
        fields["down_until"] = 0
    update_session(sid, calls=int("ms" in entry), denies=int(denied), **fields)


# --- hooks ---

def permission(verdict, reason):
    if verdict not in ("allow", "deny"):
        return None
    if verdict == "deny":
        reason = f"ohmyjev blocked this: {reason}. {BLOCK_NOTICE}"
    return {"hookSpecificOutput": {"hookEventName": "PreToolUse",
                                   "permissionDecision": verdict, "permissionDecisionReason": reason}}


def pre_tool(data, cfg, sid):
    tool = data.get("tool_name") or ""
    inp = data.get("tool_input") if isinstance(data.get("tool_input"), dict) else {}
    cwd = data.get("cwd") or os.getcwd()
    on, t = cfg["batteries"], cfg["thresholds"]
    if tool == "Bash" and on["bash_gate"]:
        state = with_policies({"command": clip(inp.get("command"), 4000), "cwd": cwd,
                               "description": clip(inp.get("description"), 300)}, cfg)
        answers, entry = call("PreToolUse", tool, state, BASH_Q, cfg, sid)
        if answers is None:
            return None
        verdict, reason = gate_bash(answers, t, on["auto_approve"])
    elif tool in WRITE_TOOLS and on["write_gate"]:
        path = str(inp.get("file_path") or inp.get("notebook_path") or "")
        if not path_allowed(path, cwd, cfg["allow_paths"]):
            entry = new_entry("PreToolUse", tool, sid)
            verdict, reason = "deny", f"{path} is outside the repo and allow_paths"
        else:

def read_transcript(path, tail_bytes=200_000):
    """User requests (oldest first) and tool names used since the last request, from the transcript tail."""
    requests, tools = [], []
    try:
        with open(os.path.expanduser(path), "rb") as f:
            f.seek(0, os.SEEK_END)
            f.seek(max(0, f.tell() - tail_bytes))
            lines = f.read().decode("utf-8", "replace").splitlines()
    except (OSError, TypeError):
        return requests, tools
    for line in lines:
        try:
            e = json.loads(line)
        except ValueError:
            continue  # the first line after a tail seek is usually partial
        if not isinstance(e, dict):
            continue
        content = (e.get("message") or {}).get("content")
        if e.get("type") == "user" and not e.get("isMeta"):
            if isinstance(content, list):  # tool results arrive as user messages with no text blocks
                content = "\n".join(c.get("text", "") for c in content if isinstance(c, dict) and c.get("type") == "text")
            if isinstance(content, str) and content.strip():
                requests.append(content)
                tools = []
        elif e.get("type") == "assistant" and isinstance(content, list):
            tools += [c.get("name") for c in content if isinstance(c, dict) and c.get("type") == "tool_use"]
    return requests, tools


def stop(data, cfg, sid):
    on = cfg["batteries"]
    if data.get("stop_hook_active") or not (on["done_check"] or on["compact_hint"]):
        return None
    requests, tools = read_transcript(data.get("transcript_path"))
    state = {
        "current_request": clip(requests[-1] if requests else "", 600),
        "last_assistant_message": clip(data.get("last_assistant_message"), 1500),
        "tools_this_turn": tools,
        "previous_requests": [clip(r, 200) for r in requests[-6:-1]],
    }
    questions = dict(STOP_Q, **(SWITCHED_Q if len(requests) >= 2 else {}))
    answers, entry = call("Stop", "", state, questions, cfg, sid)
    if answers is None:
        return None
    reason, compact = check_stop(answers, cfg["thresholds"])
    reason = reason if on["done_check"] else None
    record(entry, sid, "block" if reason else None, reason or "", compact=compact and on["compact_hint"])
    return {"decision": "block", "reason": reason} if reason else None

def emit(obj, code):
    print(json.dumps(obj, ensure_ascii=False))
    return code


def ask(args):
    """Answer one question about files, a command's output, or text. Claude gets the judgment, not the content."""
    cfg, _ = load_config()
    if args.noul:
        q = noul(args.noul)
    elif args.choice:
        if len(args.choice) < 3:
            return emit({"error": "--choice needs a question and at least two options"}, 2)
        opts = {o: o for o in args.choice[1:]}
        opts.setdefault("other", "None of the listed options fit")
        q = choice(args.choice[0], opts)
    else:
        if not 3 <= len(args.score) <= 11:
            return emit({"error": "--score needs a question and 2 to 10 levels, low to high"}, 2)
        q = score(args.score[0], args.score[1:])
    state, budget = {}, 80_000
    if args.state:
        state["state"] = args.state
    for p in args.file or []:
        if budget <= 0:
            state["truncated"] = True
            break
        try:
            text = clip(Path(p).read_text(errors="replace"), min(8000, budget))
        except OSError as e:
            return emit({"error": f"{p}: {e}"}, 1)
        state.setdefault("files", {})[p] = text
        budget -= len(text)
    if args.cmd:
        gate_state = {"command": args.cmd, "cwd": os.getcwd()}
        answers, entry = call("ask", "Bash", gate_state, BASH_Q, cfg, "cli")
        if answers is None:
            return emit({"error": "jev unavailable: refusing to run an unchecked command"}, 1)
        verdict, reason = gate_bash(answers, cfg["thresholds"], False)
        record(entry, "cli", verdict, reason)
        if verdict == "deny":
            return emit({"error": f"blocked: {reason}"}, 2)
        try:
            out = subprocess.run(args.cmd, shell=True, capture_output=True, text=True, timeout=60)
        except subprocess.TimeoutExpired:
            return emit({"error": "command timed out after 60s"}, 1)
        state.update(command=args.cmd, exit_code=out.returncode, output=clip(out.stdout + out.stderr, 20_000))
    if not state:
        return emit({"error": "give --file, --cmd, or --state"}, 2)
    answers, entry = call("ask", "", state, {"q": q}, cfg, "cli", timeout=10)
    if answers is None:
        return emit({"error": "jev unavailable"}, 1)
    record(entry, "cli", None, "")
    return emit(answers["q"], 0)

# ask-jev

Jev answers bounded questions in about 300 ms for a tiny fraction of a cent. Code reads the files or runs the command, so you get back only a typed answer with probabilities, and your context stays small.

## When to use it

- Scouting: "Which of these files handles proration?" Ask about each candidate, then open only the one that matters.
- Triage: run the failing test through `--cmd` and ask whether the cause is `bug_in_code`, `wrong_test`, or `environment`.
- Self-checks: score the risk of `git diff`, or ask whether the test output shows all tests passing.

Read the file normally when you need to edit or quote it. Jev judges; it does not write or explain.

## Usage

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/omj.py ask --file src/auth/session.py --noul "Does this file validate tokens before use?"
python3 ${CLAUDE_PLUGIN_ROOT}/omj.py ask --cmd "npm test" --choice "Why do the tests fail?" bug_in_code wrong_test environment
python3 ${CLAUDE_PLUGIN_ROOT}/omj.py ask --cmd "git diff" --score "How risky is this change to ship?" trivial moderate risky
python3 ${CLAUDE_PLUGIN_ROOT}/omj.py ask --state "user said: the app is unusable" --noul "Is this urgent?"
```

- `--file` repeats. `--cmd` passes the same bash safety gate as your own commands and is refused if the gate blocks it.
- `--choice` always gains an `other` option. `--score` takes 2 to 10 levels, low to high.
- Output is one JSON object: `noul` is the probability of yes; `choice` is a label plus per-option `probabilities` and `confidence`; `score` is a position from 0 (first level) up, with a `legend`.
- Treat below about 0.7 as "unsure". Decide in your own reasoning what to do with the number.
- `{"error": ...}` means no answer (no key, Jev down, blocked command). Fall back to reading the file yourself.

"""ohmyjev statusline segment. Paste jev_segment() into your own statusline script.

    jev = jev_segment(data.get("session_id"))   # data = the statusline JSON from stdin
    if jev:
        parts.append(jev)                       # colour it however your statusline does

Reads ~/.ohmyjev/sessions/<session_id>.json only: no subprocess, no network.
"""
import json
import os
import re
import time


def jev_segment(session_id):
    """'' when ohmyjev has no state for this session; otherwise e.g. 'jev ✓23 ⛔1 🗜' or 'jev ⚠ down'."""
    home = os.environ.get("OHMYJEV_HOME") or os.path.expanduser("~/.ohmyjev")
    sid = re.sub(r"[^\w-]", "", str(session_id or ""))
    if not sid:
        return ""
    try:
        with open(os.path.join(home, "sessions", sid + ".json")) as f:
            s = json.load(f)
    except (OSError, ValueError):
        return ""
    if not isinstance(s, dict):
        return ""
    if s.get("down_until", 0) > time.time():
        return "jev ⚠ down"
    seg = f"jev ✓{s.get('calls', 0)}"
    if s.get("denies"):
        seg += f" ⛔{s['denies']}"
    if s.get("compact"):
        seg += " 🗜"
    return seg
```

Batteries-included [Jev](https://typesafe.ai) for Claude Code. Jev is TypeSafe's decision model: state and typed questions in, probabilities out, in about 300 ms for a fraction of a cent. ohmyjev puts it in Claude Code's hooks so your agent gets a judgment layer it never has to think about.
