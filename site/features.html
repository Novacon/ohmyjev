Every feature, setting and limit.

ohmyjev asks Jev, TypeSafe's decision model, typed questions at every step a coding agent takes. Jev answers with probabilities in about 160 ms for about $0.00003, and code turns those numbers into a decision. Here is each one.

Faster

Auto-approve

Where Claude Code or Codex would stop to ask you, a command Jev is sure only reads or can be undone runs without the prompt, and so does an edit inside the repo with no credential in it. It only answers "allow" where the engine was about to ask and your settings left the call open. Off whenever you've set policies.

autoApproveClaude Code, Codex0.9 confidence, under 0.2 risk

Plain-read fast path

ls, git status, grep, cat and friends, alone, piped or chained, are cleared by code with no Jev call. Anything that could write still goes to Jev: redirects, $(…), find -exec, sed -i, git stash.

Always on, off while policies are setAll hosts

Trim long output

A shell output over 12,000 characters is split into parts, and one Jev call rates which parts your request needs: the error, the failing test, the value you asked for. The rest becomes one line saying how much was left out and how to see it.

trimOutputtrimOvertrimKeepAll hosts

Model router

One Jev call per request rates the work and the reasoning it needs, then raises or lowers effort and picks the model for general-purpose subagents. With routeMainModel on it also switches the main model; that's off by default because switching drops the prompt cache. In the flights test it sent the task to Haiku: 108 s down to 44 s.

routeEffortrouteSubagentsrouteMainModelClaude Code, omp, pi

browse

A tool for web tasks. The agent passes a URL, one goal and the words to type; jev-ultrafast runs it in its own headless Chrome, Chromium, Brave or Edge, signed in to nothing, with Jev picking each click and field. Needs uv.

browseOff by defaultClaude Code, omp, pi

Skill picker

Claude Code sends the model a line for every skill you have, on every prompt. ohmyjev leaves that list out, asks Jev whether a prompt needs a skill and which, then checks the pick does the job before naming it. A prompt no skill fits gets none.

skillPickskillGateskillMinClaude Code, with a Jev key

Stuck check

From the third failed tool call in a request, Jev reads the failures. If they repeat one approach and fail the same way, the agent is told to stop, read the error and try something else, or ask you.

stuckCheckstuckAll hosts

Auto-compact

When the task changes after a finished step and the context is at least 40% full, it compacts, keeping the new request in full.

autoCompactcompactMinPercentClaude Code, omp, pi

Safer

Bash gate

Denies a command Jev rates irreversible at 0.6 or more, or one that sends local files or secrets to an outside host at 0.7. Reversible work always passes: deleting lines, dropping a co-author trailer, uninstalling, ordinary pushes.

bashGatebashIrreversibleexfil

Say yes

Every gate also asks whether your latest message asked for exactly this call. "Delete the build folder" lets rm -rf build through. After a block, a plain "yes" works too, because the gate shows Jev the call it just blocked. "No", or a yes followed by a different command, is still denied. Policy and path denies always stand.

requested0.8

Write gate

Denies writes outside the repo and allowPaths, and writes that contain a real credential. Every worktree of the repo counts, and so does another repo the agent moves into. The path check is plain code, not Jev, and follows symlinks the way the OS does.

writeGateallowPaths

Exfil gate

Denies a WebFetch or MCP call Jev rates 0.7 or more for sending your data, files or credentials out. browse goals pass it before a browser opens.

exfilGate

Policies

Your own plain-English rules, separated by ;. Every gate checks each call against them, and no "yes" overrides one.

policies

Injection screen

Output from Bash, WebFetch, MCP, browse or a Read outside the repo that gives the model instructions gets a note telling it to treat the text as data.

injectionScreenscreenReads

Done-check

If the agent says it's done but nothing shows it ran a check, it blocks the stop once and tells the agent to verify. It reads the end of each command's output, so a passing test run counts, and a turn with no tools is never blocked.

doneCheck

Tools and commands

/omj

This session's Jev calls, errors, cost, median latency and denies, and where the key comes from, never the key. /ohmyjev is the same command.

Claude Code, omp, pi

/omj config

Lists every setting; /omj config <name> <value> changes one for the session, checked against its type. The key can't be set here, so it never lands in the transcript.

/omj stats

Opens a local dashboard of every session: totals, a 30-day chart, a table per tool and per session, and the latest denies with reasons. Built from the logs; nothing leaves the machine.

/omj off, on

Every gate, screen, check and the router off or on for this session. The enabled setting is the default for new sessions.

enabled

ask_jev

A tool the model calls to ask Jev about repo files or text without reading them into its own context: which file handles login, does this log show the failure.

askJevRepo files only, 8,000 characters each, 80,000 in all

How it decides

Every tool call gets one quick question to Jev. A clear risk is denied, a clearly safe call skips the prompt, and anything in between goes on to the host's normal flow, the same as without ohmyjev.

Before the call ~160 ms

Clearly riskyDenied, with the reason
Clearly safeRuns, no permission prompt
UnsureThe host's normal flow
Jev down, slow or no keyThe host's normal flow

After the call

Long, mostly unrelatedCut to what the request needs
The same failure, a third timeTold to change approach
Gives the model orders"Treat as data" note
None of theseOutput as is

It fails open: a middling answer, a slow or down Jev, a missing key or any error inside ohmyjev falls through to the normal flow. Jev can be wrong, so keep your deny rules in settings.json.

Install

Claude Code

/plugin install ohmyjev --marketplace Novacon/ohmyjev

2.1.287 or later. Hooks run right away.

Codex

codex plugin marketplace add Novacon/ohmyjev
codex plugin add ohmyjev@ohmyjev

Trust its hooks once in /hooks. Needs Node.

omp

omp plugin install ohmyjev

Restart the session.

pi

pi install npm:ohmyjev

Restart pi.

Set TYPESAFE_API_KEY in the shell that starts your agent, or OPENROUTER_API_KEY to reach Jev through OpenRouter. In Claude Code you can also enter it on the settings screen during install. Run /omj: its last line says where the key came from.

jev ⚠ no key

The key isn't visible to the agent. Set it in the shell that starts it, or with /plugin configure ohmyjev@ohmyjev.

jev ⚠ down

A Jev call failed or took over 1.5 s in the last 5 minutes. Gates let calls through until Jev answers again.

Blocked by mistake

Answer the agent's question with "yes". /omj shows the reason; raise that gate's threshold, turn it off, or /omj off for the session.

Nothing happens

Run claude --debug. A failing hook leaves a line naming it and the reason.

Settings

Change one for the session with /omj config <name> <value>. To keep it: /plugin configure ohmyjev@ohmyjev in Claude Code, omp plugin config set ohmyjev in omp, the ohmyjev key in ~/.pi/agent/settings.json, or ~/.codex/ohmyjev.json.

Privacy

With a key set, each check sends Jev only what it needs, cut to size. With no key, nothing goes. Logs stay in ~/.ohmyjev, readable only by you.

CheckWhat it sends
Bash gateThe command (up to 16,000 characters), the working directory, the call's description, your latest message (1,500) and, right after a block, the blocked call. Plain reads send nothing.
Write gateThe path and the new content (16,000). Writes outside the repo are denied by code before anything is sent.
Exfil gateThe tool's name and input (4,000).
Injection screenThe tool's output (6,000).
TrimYour latest message and the long output, in parts of about 1,500 characters, up to 24.
Stuck checkYour latest message and the last six failed calls: input and the end of each output.
Skill pickerEach prompt with every skill's name and one-line description.
Done-checkThe request, five earlier ones, this turn's tool calls with the end of each output, and the agent's last message.
RouterThe request (1,500).
browseThe goal and URL to the exfil gate; then each step, the page's controls and visible text to Jev.
