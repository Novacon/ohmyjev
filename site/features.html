00 / Features every feature, setting, and limit

the reference

ohmyjev asks Jev about every step your agent takes. Each check takes about 160 ms and costs about $0.00003. Demos are on the home page, the details are here.

02 / How it decides One tool call

how it decides

Every tool call gets one quick check. Risky gets blocked, safe skips the prompt, and the rest goes on like normal.

InClaude calls a tool

01 ohmyjev asks Jev ~200 ms

Clearly risky→Denied, with the reason
Clearly safe→Runs, no permission prompt
Unsure→Normal permission flow, then the tool runs
Jev down, slow, or no key→Normal permission flow, then the tool runs

02 The output comes back

Long, mostly unrelated→Cut to the parts the request needs
The same failure, a third time→Agent told to change approach
Has instructions aimed at the model→Model gets a "treat as data" note
None of these→Output as is
● ● ●what claude sees on a deny
ohmyjev blocked this: irreversible (0.95): nothing would restore what this removes or overwrites.
Do not try to work around it with another command, another tool, a different path, or an encoding that does the same thing. Tell the user what was blocked and why, and ask whether to run it anyway. If they say yes, run exactly this again: their reply then lets it through.

Fails open, removes prompts

If Jev is unsure, slow, or down, the call goes through like normal. It never adds a prompt.

Jev can be wrong, so keep your deny rules in settings.json.

03 / Install 4 steps

install it

You need a TypeSafe or OpenRouter key. These steps are for Claude Code. For the others see By host.

STEP 1

Check your version

You need 2.1.287 or later.

● ● ●shell
claude --version

STEP 2

Install the plugin

Answer y and pick a scope. Hooks start right away.

● ● ●claude code
/plugin install ohmyjev --marketplace Novacon/ohmyjev

STEP 3

Add your key

  1. The settings screen during install (kept in secure storage)
  2. TYPESAFE_API_KEY
  3. OPENROUTER_API_KEY, as ~typesafe/jev-latest
● ● ●~/.zshrc
export TYPESAFE_API_KEY=ts_...

STEP 4

Check it works

Run /omj. The last line shows where your key came from.

● ● ●/omj, last line
key: env TYPESAFE_API_KEY · typesafe · jev-1.13.0

jev ⚠ no key

Set TYPESAFE_API_KEY in the shell that starts Claude Code.

jev ⚠ down

Jev failed or was slow in the last 5 minutes. Calls go through until it's back.

Blocked by mistake

Say yes and it runs. Or raise that gate's threshold, or /omj off.

Nothing happens

Run claude --debug to see which hook failed.

07 / Privacy what each check sends

privacy

Each check sends Jev only what it needs, with secrets masked first. No key, nothing goes. Logs stay in ~/.ohmyjev.

CheckWhat it sends
Bash gateThe command (up to 16,000 characters), the working directory, the call's description, your latest message (1,500) and, right after a block, the blocked call. Plain reads send nothing.
Write gateThe path and the new content (16,000). Writes outside the repo are denied by code before anything is sent.
Exfil gateThe tool's name and input (4,000).
Injection screenThe tool's output (6,000).
TrimYour latest message and the long output, in parts of about 1,500 characters, up to 24.
Stuck checkYour latest message and the last six failed calls: input and the end of each output.
Skill pickerEach prompt with every skill's name and one-line description.
Done-checkThe request, five earlier ones, this turn's tool calls with the end of each output, and the agent's last message.
Fast compactionRecent messages in groups of 10, each cut to 1,200 characters.
Writing rulesEach final reply (6,000). The rules come from your instruction files once, pulled out by Haiku inside Claude Code.
RouterThe request (1,500).
ask_jev, find_codeThe question and repo files. Never files outside the repo.
browseThe goal and URL to the exfil gate; then each step, the page's controls and visible text to Jev.
