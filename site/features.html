00 / Features every feature, setting and limit

the reference

ohmyjev asks Jev, TypeSafe's decision model, typed questions at every step a coding agent takes. Jev answers with probabilities in about 160 ms for about $0.00003, and code turns those numbers into a decision. The home page has the demos; this page has the detail.

01 / What you get 15 features

what you get

Jev is TypeSafe's decision model: typed questions in, probabilities out, in about 200 ms for a fraction of a cent. That's cheap enough to ask about every step your agent takes, so ohmyjev asks it what to approve, what to trim, which skill to load, when the agent is stuck, and what to stop. In-process hooks, no server.

02 / How it decides One tool call

how it decides

Every tool call gets one quick question to Jev. A clear risk is denied, a clearly safe call runs without a permission prompt, and anything in between goes on to Claude Code's normal flow, the same as without ohmyjev.

InClaude calls a tool

01 ohmyjev asks Jev ~200 ms

Clearly risky→Denied, with the reason
Clearly safe→Runs, no permission prompt
Unsure→Normal permission flow, then the tool runs
Jev down, slow or no key→Normal permission flow, then the tool runs

02 The output comes back

Long, mostly unrelated→Cut to the parts the request needs
The same failure, a third time→Agent told to change approach
Has instructions aimed at the model→Model gets a "treat as data" note
None of these→Output as is
● ● ●what claude sees on a deny
ohmyjev blocked this: irreversible (0.95): nothing would restore what this removes or overwrites.
Do not try to work around it with another command, another tool, a different path, or an encoding that does the same thing. Tell the user what was blocked and why, and ask whether to run it anyway. If they say yes, run exactly this again: their reply then lets it through.

Fails open, removes prompts

Middling answers, a slow or down Jev, a missing key and any error inside ohmyjev all fall through to the normal flow. It never adds a prompt, only takes away the ones a safe call didn't need, so bypass-mode agents run fine.

Jev can be wrong, so keep your deny rules in settings.json.

03 / Install 4 steps

install it

You need a Jev key: a TypeSafe key, or an OpenRouter key. These steps are for Claude Code; on Codex, pi or omp, see By host or the install slide.

STEP 1

Check your version

Mods are still early access, so you need Claude Code 2.1.287 or later.

● ● ●shell
claude --version

STEP 2

Install the plugin

Answer y to add the marketplace and pick a scope; user scope covers every session. The hooks run right away, no restart.

● ● ●claude code
/plugin install ohmyjev --marketplace Novacon/ohmyjev

STEP 3

Add your key

  1. The settings screen during install (kept in secure storage)
  2. TYPESAFE_API_KEY
  3. OPENROUTER_API_KEY, as ~typesafe/jev-latest
● ● ●~/.zshrc
export TYPESAFE_API_KEY=ts_...

STEP 4

Check it works

Run /omj. The last line says where the key came from. With key: none every gate stays open and routing falls back to Claude Code's own classifier.

● ● ●/omj, last line
key: env TYPESAFE_API_KEY · typesafe · jev-1.13.0

jev ⚠ no key

Set TYPESAFE_API_KEY in the shell that starts Claude Code, or run claude plugin configure ohmyjev@ohmyjev.

jev ⚠ down

A Jev call failed or took over 1.5 s in the last 5 minutes. Gates let calls through until Jev answers again.

Blocked by mistake

Answer the agent's question with "yes" and it can run that exact call again. /omj shows the reason. Raise that gate's threshold in /config, turn it off, or /omj off for the session. Local MCP tools can trip exfilGate.

Nothing happens

Run claude --debug. A failing hook leaves a line naming it and the reason.

07 / Privacy what each check sends

privacy

With a key set, each check sends Jev only what it needs, cut to size. With no key, nothing goes. Logs stay in ~/.ohmyjev, readable only by you.

CheckWhat it sends
Bash gateThe command (up to 16,000 characters), the working directory, the call's description, your latest message (1,500) and, right after a block, the blocked call. Plain reads send nothing.
Write gateThe path and the new content (16,000). Writes outside the repo are denied by code before anything is sent.
Exfil gateThe tool's name and input (4,000).
Injection screenThe tool's output (6,000).
TrimYour latest message and the long output, in parts of about 1,500 characters, up to 24.
Stuck checkYour latest message and the last six failed calls: input and the end of each output.
Skill pickerEach prompt with every skill's name and one-line description.
Done-checkThe request, five earlier ones, this turn's tool calls with the end of each output, and the agent's last message.
RouterThe request (1,500).
browseThe goal and URL to the exfil gate; then each step, the page's controls and visible text to Jev.
