Claude Code mod / powered by Jev

claude code with jev wired in.

ohmyjev is oh-my-zsh for Jev, TypeSafe's decision model. One install runs it inside Claude Code as a mod. It blocks destructive commands, catches secrets and prompt injection, pushes back when the agent says done without proof, and routes effort to the turns that need it. Nobody has to approve anything.

Install ↓ In-process TypeScript / Claude Code 2.1.287+

01 / Why it exists

your agent works alone. nothing checks it.

01.1

Prompts stall unattended runs

Leave permission prompts on and a run in a parallel worktree waits hours for a click nobody is there to make. Turn them off and nothing stands between the agent and rm -rf.

01.2

One guard gets routed around

Block the write tool on its own and an agent will write the same file with a bash heredoc. The gates only hold when they load together.

01.3

Done is not verified

Agents report success before they run the check. Something has to ask for the evidence before the turn ends.

02 / Batteries

nine batteries. one install.

tool.call / Bash

Bash gate

Every shell command is rated read-only, reversible or irreversible before it runs. Irreversible or destructive ones are denied with a reason.

Deny ≥ 0.6 irreversible · ≥ 0.7 destructive

tool.call / Write

Write gate

Writes outside the repo and your allowPaths are refused by a plain path check. Inside the repo, Jev checks the content for a real credential.

Deny ≥ 0.7 credential

tool.call / Fetch + MCP

Exfil gate

Web fetches and MCP calls are checked for local files, data or keys heading to an outside host.

Deny ≥ 0.7 exfiltrates

Every gate

Policies

Your own rules in plain English, separated by semicolons. Every gate checks each call against them.

Deny ≥ 0.7 breaks a policy

tool.call / Output

Injection screen

Output from shell commands, web fetches, MCP tools and reads outside the repo is screened for instructions aimed at the model. Flagged output gets a note.

Warn ≥ 0.7 injection

Stop / Turn end

Done-check

If the agent says it's done and nothing shows it ran a check, the stop is blocked once.

Blocks once per stop

turn.start / agent.spawn

Router

Once per request, Jev rates the work and its risk. Effort moves up or down, and general-purpose subagents get the matching model.

Raise ≥ 0.3 · lower ≥ 0.6

session.measure

Auto-compact

When the task changes after a finished step and context is at least 40% full, the conversation compacts. The new request is kept in full.

Context ≥ 40% · switched ≥ 0.8

Tool / ask_jev

ask_jev

Claude asks Jev one typed question about repo files or text. Only the answer comes back into Claude's context.

noul · choice · score

03 / See it work

every call, in the transcript.

04 / Failure policy

nothing ever waits on a human.

Jev says no

The call is denied with a reason the agent can act on, ending with the same notice every time: stop, don't route around it, and tell the user what was blocked and why.

Jev is unsure

A middling answer isn't a deny. The call goes on to Claude Code's normal permission flow.

Jev is down

An error, or an answer slower than 1.5 seconds, lets the call through. The statusline shows jev ⚠ down for five minutes.

No key

Every call passes through, and the statusline shows jev ⚠ no key.

ohmyjev has a bug

Any error inside ohmyjev lets the call through, the same as Jev being down.

One call per event

Each event makes at most one Jev call carrying all its questions. That takes about 300 ms and costs a fraction of a cent.

05 / Install

three steps. no dependencies.

Step / 01 / Start here

Install the mod

Claude Code 2.1.287 or later. Mods are still early access.

/plugin marketplace add Novacon/ohmyjev
/plugin install ohmyjev@ohmyjev

Step / 02

Add a key

Enter it in /config, where Claude Code keeps it in secure storage, or export it. OPENROUTER_API_KEY also works.

export TYPESAFE_API_KEY=ts_…

Step / 03

Check it

Shows this session's calls, errors, cost, median latency and denies, and where the key comes from. It never prints the key.

/jev

06 / Trust

a second opinion. not the only lock.

Jev is a classifier, and classifiers can be wrong. ohmyjev sits next to your settings.json deny rules and doesn't replace them. Every decision is one line in ~/.ohmyjev/log/<session>.jsonl, and only you can read it.

07 / Source

mit licensed. read every line.

Three TypeScript files running inside Claude Code as function hooks, plus a statusline segment in Python. No packages to install. The question rubrics come from disler/ten-levels-of-jev.
