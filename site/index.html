04 / Say yes bypass mode, kept safe

nothing irreversible until you say yes

Bypass mode is fast because nothing stops the agent. ohmyjev keeps it that way and stops only what can't be undone. It never adds a prompt: when it blocks, the agent tells you why and asks.

Stopped

  • rm -rf, force pushes, reset --hard, dropped tables
  • curl or scp sending your keys or files out
  • Writes outside the repo, and credentials written into it
  • Pages and files that try to give your agent orders

Not stopped

  • Deleting lines, dropping a co-author trailer, uninstalling
  • Ordinary commits and pushes, installs, builds, tests
  • Anything you asked for by name, or said yes to after a block

05 / Install Claude Code · Codex · omp · pi

install it

You need a TypeSafe key, or an OpenRouter key. Everything is on by default except browse: turn it on with /omj config browse on. Every feature and setting is on the features page.

CLAUDE CODE

One command

2.1.287 or later. Hooks run right away.

/plugin install ohmyjev --marketplace Novacon/ohmyjev

How we measured

  1. Google Flights, one-way Zurich to London on Nov 20, 2026, in claude -p on an Apple silicon Mac, three runs each, all reaching the results. Medians: 108 s for Claude Code as shipped (runs of 108, 339 and 31 s) and 44 s with the router picking Haiku (routeMainModel on), both end to end in Claude Code; 9.9 s for browse called directly (runs of 10.5, 7.4 and 9.9 s). Inside Claude Code, router and browse together took 18 s, the extra being Claude Code starting and Haiku's two turns. Times include startup.
  2. Every Jev-judged shell command in the author's logs: 637 of 865 clear auto-approve's bar (not irreversible at 0.9 confidence, under 0.2 for wiping or sending data out). Separately, 31% of 4,888 real commands are plain reads that skip Jev.
  3. All Jev calls in those logs: $0.13 for 3,877 calls over 90 sessions, median 163 ms, 95th percentile 239 ms.
  4. A 420-line test log with one failure: 20,471 characters in, 4,582 out, the failure kept.
  5. tests/live.ts: 28 real commands with expected verdicts, against the live Jev.
