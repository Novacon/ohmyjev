Nothing irreversible until you say yes.

Bypass mode is fast because nothing stops the agent. ohmyjev keeps it that way and stops only what can't be undone.

  • rm -rf, force pushes, reset --hard, dropped tables
  • curl or scp sending your keys or files out
  • Writes outside the repo, and credentials written into it
  • Pages and files that try to give your agent orders

It never adds a prompt. When it blocks, the agent tells you why and asks; your yes runs that exact command.

what the agent sees

Install in a minute.

You need a TypeSafe key, or an OpenRouter key. Everything is on by default except browse; turn it on with /omj config browse on.

Claude Code

/plugin install ohmyjev --marketplace Novacon/ohmyjev

Hooks run right away, no restart.

Codex

codex plugin marketplace add Novacon/ohmyjev
codex plugin add ohmyjev@ohmyjev

Then trust its hooks once in /hooks.

omp

omp plugin install ohmyjev

Restart the session after installing.

pi

pi install npm:ohmyjev

Settings go under ohmyjev in pi's settings file.

How we measured

  1. Google Flights, one-way Zurich to London on Nov 20, 2026, one adult, economy, run in claude -p on an Apple silicon Mac, three runs each, all reaching the results. Medians: 108 s as shipped (Opus 5.5 at xhigh effort, Playwright MCP, runs of 108, 339 and 31 s), 44 s with the router picking Haiku (routeMainModel on), 18 s with the router and browse. Times include startup.
  2. Every Jev-judged shell command in the author's decision logs: 637 of 865 rated not irreversible with 0.9 confidence and under 0.2 for wiping or sending data out, the bar auto-approve uses. Separately, 31% of 4,888 commands from past sessions were plain reads that skip Jev.
  3. All Jev calls in those logs: $0.13 for 3,877 calls, median latency 163 ms, 95th percentile 239 ms.
  4. A 420-line test log with one failure: 20,471 characters in, 4,582 out, the failure kept.
  5. tests/live.ts in the repo: 28 real commands with their expected verdicts, against the live Jev.
